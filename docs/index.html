MCP Weather & Calendar Tools

The 6 tools exposed

get_alerts(state)

Active weather alerts for a US state, from the live National Weather Service API.

get_forecast(lat, lon)

5-period detailed forecast for any US coordinate.

create-event(...)

Schedules a real macOS Calendar event via AppleScript automation.

list-calendars()

Lists every calendar available on the Mac (Personal, Work, etc.).

list-today-events()

Returns today's full schedule.

search-events(query)

Keyword search across calendar events.

Self-healing in action

    
Real maintenance events, pulled from the scraper's own config notes — evidence the system adapts when a company changes its hiring stack.

    

      
↻
Uber
Greenhouse board token silently changed from uber to uberfreight — detected and fixed by the alternate-token fallback list.

      
↻
Palo Alto Networks
Moved off Greenhouse entirely, onto Workday — flagged verified:false pending re-confirmation rather than silently failing.

      
↻
Kearney
Moved off Lever — same self-flagging behavior, with a Lever-alternates list queued for retry.

      
✕
BCG, Apple, Bain, LinkedIn
Removed from Workday tracking entirely after their endpoints started blocking unauthenticated requests (HTTP 401) — rather than logging silent failures forever.

Recognized as running custom in-house career sites, not Workday — routed to SmartRecruiters or manual config instead of wasting scrape attempts.
